Import Data

Import monthly statements (deposits, expenses and driver pay) from a CSV file or an Excel workbook

{# Instructions Card #}

Statement format

  • A .csv file (one month) or an .xlsx workbook: every month sheet in it is imported, other sheets are skipped
  • One row per transaction with a DATE column and a column per amount (header names are matched automatically)
  • DEPOSIT + DEPOSIT FROM become paid invoices for that customer; PAY + PAY TO become driver pay
  • Dates like 01-02-2025, 2/3/2025 or real Excel dates; amounts like $1,250.50; - and empty cells mean zero
  • You see a preview first and nothing is saved until you confirm. Uploading the same file again does not create duplicates.

Expense columns

IRP PARKING ON SITE TRUCK CHECK CHARGE INSURANS / INSURANCE TOLL FUEL OTHER / PARTS CHASSIS

A file with the columns DATE, Category, Amount and optionally Description is also accepted.
